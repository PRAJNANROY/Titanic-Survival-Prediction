# Data Science Assignments & Titanic Data Cleaning Mini Project

This repository contains Python solutions for fundamental data preprocessing tasks using `pandas` and `scikit-learn`, along with a complete data cleaning pipeline for the Titanic dataset.

## Repository Structure

```text
data-science-assignments/
├── assignment_1_load_and_summarize.py
├── assignment_2_missing_data_imputation.py
├── assignment_3_categorical_encoding.py
├── mini_project_1_titanic_cleaning.py
├── requirements.txt
└── README.md
```

## Setup & Usage

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run individual assignments:
   ```bash
   python assignment_1_load_and_summarize.py
   python assignment_2_missing_data_imputation.py
   python assignment_3_categorical_encoding.py
   ```

3. Run Mini Project 1 (place Kaggle's `train.csv` in the root folder first):
   ```bash
   python mini_project_1_titanic_cleaning.py
   ```
   This outputs `age_distribution.png` and `titanic_cleaned.csv`.
